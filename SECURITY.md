# Security Policy

## Supported Release Line

Hatch currently supports the latest commit on `main`.

This is a public portfolio release, not a commercial support program. Security fixes are handled on a best-effort basis through the current release line.

## Reporting a Vulnerability

Please report security concerns privately by email:

`arvind_soni@hotmail.com`

Include:

- a concise description of the issue;
- affected files, routes, commands, or services if known;
- reproduction steps;
- whether local data, app-lock sessions, generated documents, or provider secrets may be affected.

Please do not include real API keys, private CV data, or sensitive job-search material in the report.
