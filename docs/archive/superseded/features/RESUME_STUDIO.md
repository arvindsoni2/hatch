# Resume Studio

Resume Studio builds a coordinated CV and cover-letter DOCX pack from grounded profile evidence.

- Choose from 10 public ATS-safe templates.
- Configure page target, density, section order, accent colour, and a safe font.
- Use deterministic template recommendations after job-description analysis.
- Treat the HTML preview as approximate. DOCX remains the source of truth.
- Configure global defaults in Profile Settings and override them per generation.

Legacy template IDs remain hidden aliases, so existing settings continue to work. PDF export and full inline resume editing remain unavailable.
