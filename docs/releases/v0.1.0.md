# Hatch v0.1.0 — Public Portfolio Release

Hatch is a self-hosted, human-in-the-loop workspace for job discovery, CV tailoring, application tracking, and interview preparation. It runs locally, keeps user data on the host by default, and requires explicit human review before any external application action.

## Verified highlights

- Guided installers for Linux, macOS, and Windows that prepare the lightweight Hatch stack and let users defer AI setup.
- Local-first workflow covering onboarding, role discovery, CV Studio, applications tracking, and interview preparation.
- Host-managed provider secrets, local app lock, and protected backend APIs.
- Optional bundled local `llama.cpp` model services for users who want on-device AI workflows.

## Privacy and human-review boundaries

- Hatch does not submit applications automatically.
- Generated CVs and cover letters require human review.
- Cloud provider secrets stay host-managed and out of the browser.
- DOCX remains the source of truth for generated CV output.

## Known limitations

- Job-source reliability can vary because third-party boards change access controls, rate limits, and markup.
- Browser CV preview is approximate because DOCX remains the source of truth.
- Local model speed and quality depend on the selected model and the host machine.
- PDF export remains capability-gated and may be unavailable unless a supported converter is configured.

## Install this exact release

The root README intentionally advertises the rolling `main` installer path. The commands below are pinned to `v0.1.0` so this release can be reproduced exactly.

### Linux and macOS

```bash
curl -fsSL https://raw.githubusercontent.com/arvindsoni2/hatch/v0.1.0/install.sh | bash
```

### Windows PowerShell

```powershell
iwr https://raw.githubusercontent.com/arvindsoni2/hatch/v0.1.0/install.ps1 | iex
```

After installation, open <http://localhost:3000>. The protected backend API documentation is available at <http://localhost:8000/docs>.

## Upgrade and uninstall notes

- `hatch update` is intended for managed installs and refuses to run when the managed checkout is dirty.
- `hatch uninstall` is non-destructive by default and preserves host-managed user data unless purge flags are supplied deliberately.
