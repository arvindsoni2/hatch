# Applications

Applications is the lifecycle board for roles you are tracking.

## User Actions

- add an application manually
- import from URL
- move roles between lifecycle states
- open watched companies from the Applications workflow

## Automatic Behavior

- protects invalid transitions
- keeps preparation and applied states distinct
- links preparation and interview workflows to application records

## Common Empty State

When no applications exist, the board highlights manual entry, URL import, and watched companies instead of leaving the purpose unclear.
