# Today

Today is the current-work dashboard. It pulls together pending review items, ready applications, watched-company jobs, follow-ups, and agent activity.

## User Actions

- review shortlisted roles
- open CV Studio
- open Interview Prep
- mark ready packages as applied

## Automatic Behavior

- shows pending approvals and readiness state
- surfaces watched-company results in the same workflow
- can show an AI setup reminder when AI configuration is incomplete

## Common Empty State

If no roles are ready yet, Today stays useful as a status board rather than an error screen.
