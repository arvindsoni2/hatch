# User Guide

Hatch is a self-hosted workspace for job discovery, application preparation, tracking, and interview preparation.

## What Hatch Does

- discovers roles from enabled sources
- scores roles against your profile
- prepares reviewable CV and cover-letter packs
- tracks the application lifecycle
- supports interview preparation and reusable answers

## What Hatch Does Not Do

- automatically submit applications
- automatically contact recruiters
- require cloud AI

## Main Workflow

1. Install and open Hatch.
2. Create the local app-lock password.
3. Complete onboarding and save the search profile.
4. Review Today and Pipeline.
5. Generate CV packs only for roles you choose.
6. Apply externally and track the real outcome in Applications.
7. Use Interview Prep and Question Bank once a role progresses.

## Common Messages

- AI not configured yet
- Missing provider secret
- Hardware not detected yet
- No applications tracked yet
- No jobs discovered yet

## Privacy Notes

Hatch keeps data local by default, treats cloud AI as opt-in, and requires human review before any external application step.
