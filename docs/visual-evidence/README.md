# Visual Evidence

This directory holds screenshots that are still part of the current Hatch release story.

## Retention Rule

- Keep evidence here when it is referenced by the current README or user guide.
- Keep evidence here when it is generated by the maintained screenshot workflow in `frontend/e2e/readme-screenshots.spec.ts`.
- Keep evidence here when it is intentionally maintained as a current regression baseline or release artifact.
- Move PR-only screenshots and retired UI captures to [archive visual evidence](../archive/visual-evidence/).

Evidence tied only to a merged PR is archival. Evidence tied to the current product or release workflow remains current.
